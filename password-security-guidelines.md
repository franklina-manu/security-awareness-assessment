# Password and Multi-Factor Authentication Guidelines

## Purpose
Help employees protect accounts from unauthorised access.

## Good password practices
- Use a long, unique password or passphrase for each account.
- Prefer a password manager approved by the organisation to create and store unique passwords.
- Never share passwords with colleagues, managers or support staff.
- Never reuse a work password on personal websites.
- Do not store passwords in plain text, unprotected documents or sticky notes.
- Change a password promptly if compromise is suspected or confirmed, and follow the organisation's policy.

## Multi-factor authentication (MFA)
MFA adds another verification step beyond a password. Use MFA wherever it is available, especially for email, remote access, administrator accounts and financial systems.

- Never approve an MFA prompt you did not initiate.
- Never share one-time passcodes or recovery codes.
- Report repeated or unexpected MFA prompts immediately.
- Prefer phishing-resistant MFA, such as FIDO2 security keys or passkeys, where supported and approved.

## If you think an account is compromised
1. Contact the IT/security team using the approved channel.
2. Follow the incident-response instructions.
3. Change the password through the trusted company sign-in page if instructed.
4. Review account activity with the IT/security team.
5. Do not delete suspicious messages or evidence unless instructed.

## Employee checklist
- [ ] I use unique passwords for work accounts.
- [ ] I use an organisation-approved password manager where available.
- [ ] I have enabled MFA where required.
- [ ] I never share passwords or MFA codes.
- [ ] I report unexpected MFA prompts.

## Important note
The organisation's password standard and identity-access policy take precedence. This guide is general awareness material, not a replacement for internal policy.
