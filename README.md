# Security Awareness Assessment Project

## Project overview
This beginner-friendly project demonstrates how an organisation can educate employees about common cybersecurity risks and check whether key security messages are understood.

**Scenario:** You are supporting the security team at a fictional company, SecureCorp. You have been asked to prepare a short employee awareness pack covering phishing, password security, social engineering and safe handling of information.

**Project type:** Cybersecurity awareness, governance and documentation  
**Level:** Beginner  
**Tools:** Markdown, Microsoft Excel or Google Sheets  
**Scope:** Educational tabletop material only. All people, messages and company details are fictional.

## Objectives
- Explain common signs of phishing and social engineering.
- Encourage safer password and multi-factor authentication practices.
- Promote secure handling of company and customer information.
- Assess awareness with a short knowledge check.
- Recommend practical improvements based on the assessment.

## Repository contents
| File | Purpose |
|---|---|
| `phishing-awareness-examples.md` | Fictional phishing examples and warning signs |
| `password-security-guidelines.md` | Practical password and MFA guidance |
| `social-engineering-awareness.md` | Social engineering risks and response steps |
| `data-protection-guidelines.md` | Safe handling of sensitive information |
| `awareness-assessment.xlsx` | Ten-question knowledge check and facilitator answer key |
| `recommendations.md` | Suggested awareness actions and follow-up plan |

## How to use this pack
1. Read the awareness guides.
2. Use the fictional examples to discuss warning signs. Do not send them as real phishing messages.
3. Give participants the quiz sheet without the answer key.
4. Review the answers and identify topics that need more explanation.
5. Adapt the recommendations to the organisation's policies and applicable laws.

## Key learning outcomes
After reviewing this pack, an employee should be able to:
- recognise common phishing indicators;
- use unique passwords and MFA;
- verify unusual requests through a trusted channel;
- handle sensitive information carefully; and
- report suspected security incidents promptly.

## Limitations
This is a self-directed portfolio exercise, not a formal audit, penetration test, compliance assessment or certification. The sample quiz does not prove that an actual workforce has completed training. Any real organisational exercise should be approved by the organisation and aligned with its policies.
